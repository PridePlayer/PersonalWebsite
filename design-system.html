stellingamp 设计系统 · 黛紫夜

这是个人站点 stellamp.me（作者网名 prideplayer）的官方设计系统。整体走「编辑式极简 + 暗色档案」路线：衬线标题建立气质，无衬线正文保证可读，雾紫（#8A7BB0）作为唯一强调色，克制地用在链接、按钮、标签与规则线上。

Color Tokens

色彩系统 · 黛紫夜

暗色主题的核心逻辑是「反转而非单纯压暗」：背景压到极夜黑，所有文字从深变浅（标题→近白，正文→浅紫灰，元信息→中紫灰），强调色统一为雾紫。层级完全靠「明度 + 紫调」区分，不靠多彩。

Typography

字体排印

双字体体系：Noto Serif SC（衬线）只用于标题、引用、品牌字，建立编辑气质；Noto Sans SC（无衬线）用于正文、UI、元信息，保证屏幕可读性。字重仅用 Regular(400) / Medium(500) / SemiBold(600) 三档，避免杂乱。

一、为什么不用现成的

市面上的壁纸软件要么太重，要么广告太多。我想要的是轻、干净、且能离线运行的东西。跨平台是硬需求——我自己用 Windows，朋友多用 macOS，总不能只服务一边。

做软件最难的不是写第一行代码，而是把想做完这件事，一天天坚持下去。

—— 写在 Starte 上线那天

二、技术选型与结构

核心只是一个星空渲染循环，把它挂到系统壁纸接口上。下面这段是引擎初始化的骨架：

// 初始化星空壁纸引擎
const engine = new StarteEngine({
  source: 'assets/starfield/',
  fps: 30,
});
engine.start();
